# Simulador de recortes · IRPF de Vox

Simulador de ATTAC España. Calcula cuánto se ahorraría un hogar con la rebaja del IRPF que propone Vox, cuánto perdería en servicios públicos y permite elegir qué partidas recortar (sanidad, educación, pensiones, desempleo, dependencia, familia, exclusión social, vivienda, transporte y cultura) hasta cubrir los 85.000 millones que, según Hacienda, costaría la medida.

Página única (`index.html`), sin dependencias ni servidor. Se publica con GitHub Pages.

## Fuentes
- Coste de 85.000 M€: Ministerio de Hacienda, rueda de prensa del 13/10/2026.
- Gasto por funciones: IGAE, COFOG 2020-2024 (datos de 2024).
- Metodología del IRPF: sueldovox.es.
